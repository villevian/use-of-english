Conditionals, Wishes
& Unreal Past

"If only I had studied this earlier" — that's literally Type 3. Let's fix that.

Type 1 — Real
if + present form → will / can / may / must
+ bare infinitive
✓ True or likely — present or future
If you keep scrolling,
you will regret it.
Type 2 — Unreal Present
if + Past Simple
/ Past Cont. → would / could / might
+ bare infinitive
✗ Untrue now · also for advice
If I were you,
I wouldn't check that feed. (advice)
Type 3 — Unreal Past
if + Past Perfect
/ Past Perf. Cont. → would / could / might
+ have + past participle
✗ Contrary to past facts · regrets
If she had listened,
she would have known.
⚠️ Comma rule
If-clause first → use a comma.
If-clause second → no comma.
If you are ill, stay in bed.
BUT: Stay in bed if you are ill. (no comma)
🔄 only if → inversion
When only if opens a sentence, subject + verb in the main clause swap order.
Only if you have a ticket will you be allowed in.
📝 were vs was
In Type 2 formal English, use were for all persons after if.
If he were / was rich, he would travel the world.
🚫 will/would/should in if-clauses
Normally avoided — but allowed for request, annoyance, doubt, or insistence.
If she should call, put her through. (= I doubt she will)
Other conditional connectors
unless = if not 🇺🇦 якщо не / хіба що
🇬🇧Unless you practise, you won't improve.
🇺🇦Якщо ти не будеш практикуватися, ти не покращишся.
provided / providing (that) = if, and only if 🇺🇦 за умови що / якщо тільки
🇬🇧I'll help, provided that you do your part.
🇺🇦Я допоможу, за умови що ти зробиш своє.
as long as · on condition (that) = only if the condition is met 🇺🇦 доки / поки / за умови що
🇬🇧As long as you're honest, we can work it out.
🇺🇦Доки ти чесний, ми можемо це вирішити.
in case = because it might happen 🇺🇦 на випадок якщо / про всяк випадок
🇬🇧Take an umbrella in case it rains.
🇺🇦Візьми парасолю на випадок дощу. ⚠️ Не результат — причина!
but for + -ing / noun = without / if it hadn't been for 🇺🇦 якби не / без
🇬🇧But for her help, we would have failed.
🇺🇦Якби не її допомога, ми б провалилися.
otherwise · or else = if not (warns of consequence) 🇺🇦 інакше / а то / а інакше
🇬🇧Hurry up, otherwise we'll miss the train.
🇺🇦Поспішай, інакше ми запізнимося на потяг.
supposing · what if = imagine that / what would happen if 🇺🇦 а що якщо / припустімо що
🇬🇧Supposing you won the lottery, what would you do?
🇺🇦А що якщо б ти виграв у лотерею — що б ти зробив?
even if = regardless of whether 🇺🇦 навіть якщо / навіть коли
🇬🇧Even if it rains, we'll go out.
🇺🇦Навіть якщо буде дощ, ми підемо гуляти.
only if = exclusively this condition → inversion 🇺🇦 лише якщо / тільки якщо
🇬🇧Only if you apologise will I forgive you. ⚠️ інверсія!
🇺🇦Тільки якщо ти вибачишся, я пробачу тебе. (інверсії немає)
💡 unless always takes a positive verb: Unless she stops = If she doesn't stop  ·  Never: Unless she doesn't stop
